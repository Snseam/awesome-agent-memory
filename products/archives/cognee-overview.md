# Cognee — snapshot

## What It Is

Cognee positions itself as "the brain behind your agents" — a memory and knowledge-management layer between data sources and AI agents, enabling them to build, store, and reason over structured world models.

## Core Differentiators

- **Auto-extracted ontologies and managed world models** rather than plain vector databases.
- **Memory that learns from usage patterns**, improving through each interaction without manual retraining.
- **Durable cross-session memory** that persists and compounds over time.

## Pipeline Architecture

Three stages:

1. **Ingest** — Connects to 28+ data sources (warehouses, vector stores, files, APIs, Slack) with automatic parsing and embedding.
2. **Reason** — Builds and manages ontologies, stores fine-grained permissions, and enables recall tuning.
3. **Act** — Agents retrieve memory through compatible runtimes.

## Supported Integrations

- **Agent runtimes**: Claude Code, LangGraph, OpenClaw, MCP-compatible systems, CrewAI, Cursor, Continue.
- **Data sources**: Snowflake, Postgres, PDFs, Markdown, REST APIs, Slack.
