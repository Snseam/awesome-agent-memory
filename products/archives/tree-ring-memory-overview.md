- Status: protocol-preview.

- Public runtime: Rust-native CLI and crates.
- Storage: SQLite/FTS durable store, normally under `.tree-ring/`.
- Main CLI surfaces: `init`, `remember`, `recall`, `forget`, `evidence`, `export`,
